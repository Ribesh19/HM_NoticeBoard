# Starter deck — `board.pptx`

The notice board starts from this deck instead of a blank file. It recreates
the eight original slides (welcome, announcements, birthday, events, values,
safety, kudos, document) in the Hockley Mint brand style.

## Using it

1. Copy `board.pptx` to the shared drive as **`S:\NoticeBoard\board.pptx`**.
2. From then on, your colleague just opens that file in PowerPoint, edits, and
   saves. The Pi picks up the change within ~20 seconds.

Notes for whoever edits it:

- **Keep the top-right corner of each slide fairly clear** — the live clock and
  weather pill float there on the TV.
- **The "Add a photo" box** on the birthday slide is a placeholder — drop a real
  photo over it (Insert → Picture) and delete the dashed box.
- **Embed fonts** so the look survives conversion on the Pi:
  PowerPoint → File → Options → Save → *Embed fonts in the file*.
  (The Pi renders with metric-compatible fonts, but embedding is safest.)
- Add, remove, reorder, or hide slides freely — whatever is in the deck is what
  shows on the TV, in order.

## Regenerating it

The deck is generated by a script so it can be rebuilt or tweaked:

```bash
pip install python-pptx
python starter-deck/build_deck.py        # writes starter-deck/board.pptx
```

Brand colours, fonts, and per-slide layout all live in `build_deck.py`.
